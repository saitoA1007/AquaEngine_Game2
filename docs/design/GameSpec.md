## 1. 制作の前提

## 2. 目指す体験

- **一番の売り:** 敵に囲まれて「やばい!」となったときの氷塊の気持ちよさ。
- **欲張る要素:** チャージ中は氷霧や氷塊より氷ゲージの溜まりが遅いが、一気に溜めて放つと爽快。溜めるリスクと放つリターンがあり、裏で虎視眈々と狙い続ける要素になる。
- **飽きさせない要素:** 敵がだんだん増え、難易度だけでなく爽快感も上がる。後半ほど面白く、何度もやりたくなるテンポにする。

## 3. 確定仕様

### 操作

- 操作は移動とAボタンのみ。ワンボタンのゲームとして、狙い操作は入れない。
- Aは長押しでチャージし、離すと氷霧を発生させる。単押しでも発生する。
- チャージ中の移動速度は通常どおり。

### 氷エリアと凍結

- プレイヤーは常に氷のエリアをまとう。
- エリア内の敵は、何もしなくても徐々に凍っていく。チャージ中も同じ速さで凍る。
- 徐々に凍る進行は「凍った状態」で止まる。これだけでは敵を倒せない。
- 後半は敵の氷ゲージの閾値が上がり、徐々に凍らせるだけでは凍らせきれない。序盤は立っているだけでも凍るが、後半はそうならない。
- 凍った敵は完全に停止する。触れてもダメージを受けない。
- 凍った敵は壁になる。プレイヤーと敵を小さめにして、ぶつかることが不利にならないようにする。
- 動いている敵は、凍った敵の壁を避けて回り込む。
- 凍ってから10秒ほどで氷が砕けて、敵は解放されて再び動く。この砕けでは敵は倒れず、氷塊も出ない。

### 氷霧

- 氷エリア内に発生し、敵の氷ゲージを大幅に進める。
- 凍った敵に当たると、威力に関係なく砕けて倒れる。氷と一緒に敵本体もバラバラになる。
- 同じ1発で凍った敵は、その1発では砕けない。
- 敵の弾とビームは氷霧では消せない。
- 単押しは、チャージより範囲が狭く、威力も弱い。
- チャージすると範囲と威力が上がる。
- 氷霧には単押し・チャージ共通のクールタイム(既定0.1秒)があり、その間は再発動できない。移動はクールタイム中も常にできる(硬直ではない)。
- 氷霧の見た目は[A3_Effects.md](A3_Effects.md)で確定。中心から32方向へ霧が吹き出して縁で止まり、冷気が上がり、画面が一瞬光る。

### 氷塊

- 倒して砕けた敵から氷塊が生まれ、その場に落ちる。連鎖で砕けた敵の氷塊も同じ。
- Aのチャージ中に氷塊へ近づくと、自分の上に集まる。落ちた時点でチャージ中なら、そのまま集められる。
- 氷塊を持った状態で氷霧を発生させると、持っている全部が飛ぶ。単押しでも飛ぶ。
- 氷塊が狙う範囲は、その氷霧の範囲。範囲内に敵がいなければ氷塊は消費しない。
- 1個目は、範囲内で移動方向にいる一番近い敵を狙う。静止中は一番近い敵を狙う。
- 2個目以降は、直前の敵の最寄りへ順番に連鎖する。
- 全敵に全氷塊が同じ分だけ飛ぶ。
- 凍っていない敵には大幅な凍結を与え、凍っている敵はそのまま破壊する。
- 同じ敵に複数当たると、凍結から破壊まで一度に進む。

### プレイヤーの被弾

- HPはアイコン式で、初期HPは3。
- 敵との接触か敵の攻撃で1減る。凍った敵との接触は除く。
- 被弾後は短い無敵時間がある。無敵時間のあいだ、自機は点滅する。
- 被弾すると、HPアイコンの失った分の核が砕け、欠片が枠の中に積もって暗くなり、コントローラーが振動する(詳細は[HUD_HpIcon3D.md](HUD_HpIcon3D.md))。
- HPが0になるとゲームオーバー。ゲームの世界が止まり、「GAME OVER」が出て、少し待つと「Aで再開」が出る。AかSpaceでGameシーンを最初からやり直す。リザルトとタイトルへの遷移はC5で決める(詳細は[C3_HUD.md](C3_HUD.md))。

### HUD

- 左上にHPアイコン、右上に「PHASE」の文字。フェーズの色はボーナスでもボスでも同じ。氷塊の所持数、レベルの文字、経験値バーは表示しない。
- 位置、大きさ、色は`DebugParameter`で調整できる。
- HPアイコンは3Dで、六角形の枠の中で正八面体の核が回る。影を付けず、平らな色で描く([HUD_HpIcon3D.md](HUD_HpIcon3D.md))。見た目の基準は[ArtDirection.md](ArtDirection.md)。

### 敵

- 全方位から襲ってくるヴァンサバ形式。
- 属性は熱側で、色はオレンジ系統。人型は避け、Primitiveか簡単な生物にする。
- 破片は1体あたり最大15個(調整値)。現行のモデルは8欠片。目標は同時50体の破砕。
- 計測結果(Release、64体を一斉に破砕): 破片の更新を並列化して25ms超のフレームは減ったが、敵が中心に集まった状態で氷霧を使うと、一瞬のカクつきが残る。その状況が起きにくい前提で進める。
- 氷の殻は全敵共通でよい。
- 撃破時は、氷の殻の破片(全敵共通の分割モデル)を飛ばす。敵の種類ごとの分割モデルは作らない。オレンジの敵本体の破片は廃止した。破片は球の殻を12個に割ったモデルで、重力で落ちて地面で跳ね、滑って縮んで消える([A3_Effects.md](A3_Effects.md))。
- 自然に解放されるときは、殻が縮んで溶ける(破片は飛ばない)。氷霧で砕かれても倒れない敵が解放されるときは、氷の殻の破片が飛ぶ。
- 種類は今後も追加する予定。一覧で見られる形で管理する。
- 氷ゲージの閾値は敵の種類が持ち、後半は閾値の高い種類を出す。
- 敵の弾とビームは凍った敵を貫通する。
- 弾を撃つ敵は、凍ると発射しなくなる。ビームの敵は、凍っても出ているビームは消えるまで残るが、次からは撃たない。

| 種類 | 動き | 攻撃 |
| --- | --- | --- |
| 迫る敵 | ただ迫ってくる | 接触 |
| 速い敵 | 速く迫ってくる | 接触 |
| 射撃の敵 | 移動が遅い。近づくと避けるが、遅くて簡単に追いつける | 移動中も単体の弾を撃つ |
| ビームの敵 | 未定 | プレイヤーを狙う → 固定 → 発射 → クールタイムを繰り返す。一直線に無限に伸びるビーム |
| 全方位の敵 | 画面内を自由に移動する。画面外へ行こうとすると反射して戻る | 全方位に弾を撃つ |

### 成長と進行

- 敵を倒すと経験値が上がり、一定値を超えるとフェーズが進む。強化はなく、レベルという言葉も使わない。
- 1回の氷霧から飛んだ氷塊で砕いた数を、大きな白い数字と、その右下の小さな水色の「HIT!」で数え上げる(縁取りと影つき。後ろに氷の破裂の画像)。氷霧で倒した分は数えない。氷塊で1体だけ砕いたときも1から出す。新しく砕けた敵の位置へ移って数が増え、数が大きいほど数字が大きい。表示の全体は画面の内側に収まる位置へ寄せる。一定時間増えなければ消える。同時に出せる表示は8つまで(詳細は[C3_HUD.md](C3_HUD.md))。
- 難易度は、フェーズごとに、最大数(フェーズ全体の同時数)、種類ごとの重み(0で出現しない)、1回に出す数、スポーンの間隔を決めて調整する。値はフェーズ表(JSON)で持つ。
- 敵のスポーンは一定間隔。
- 通常モードは10フェーズ、1プレイ5〜8分。
- 5フェーズ目と9フェーズ目はボーナスフェーズ。敵が一発で凍り、数が非常に多く、氷塊を一気に放てる。ボーナス専用の処理は作らず、一発で凍る設定の敵を多く出して表す。
- ボーナスも他のフェーズと同じく経験値で終わる。一気にフェーズが進んで短く終わることも気持ちよさとして許容する。
- 10フェーズ目はボス。複数回砕いて倒す。ボス戦でも雑魚を出して、氷塊を使えるようにする。
- フェーズの上限は10で、ボス戦中はフェーズが進まない。ボス撃破でクリア。
- 無限に遊べる無限モードを用意する。

### フィールドとカメラ

- 広い円形のフィールドで、端に境界を置く。
- カメラはプレイヤーに追従する固定角度。氷塊の連鎖などの演出でカメラが動くことはあり得る。

### 見た目

- 雪と氷の世界。PBRとレイトレーシングを活かせる、物理的な立体感のある見た目にする。
- プレイヤーは氷属性で水色系統。
- 背景は白と青が混ざった少し暗い色にして、ライティングを映えさせる。
- ボクセル調にはしない。
- 世界観は「凍土の番人」を仮の参考にする。未確定だが、モデルはこれをもとに作ってよい。
    - 溶けていく世界で最後に残った冷気の核が主人公。敵を砕くほど世界が再び凍っていく。

### 負荷の目安

- RTX 4060 Laptop、Release、1280×720での測定。プレイ会PCでの値ではない。
- 通常の敵は4000体まで、凍結は500体まで60fps。敵の数自体は制約にならない。

- 氷エリアの半径と凍結の速さ(実装後に調整する)。
- ビームの敵の移動。
- 解放された敵が再び撃ち始めるタイミング、ビームの狙い中に凍ったときの処理。
- 凍結の進み具合の見せ方。因果が見えるように、進行が見える形にする方針。

## 5. 置き換えた判断

- 2026-11-13: 強化(レベルアップで範囲、威力、移動速度から1つ選ぶ)をなくした。遊んでみると毎回「範囲」しか選ばず、止まってすぐ再開するのに違和感があり、効果も感じられなかったため。人間の判断。範囲、威力、移動速度は固定の値で、調整は人間が行う。「レベル」という言葉はなくしてフェーズだけにし、フェーズは経験値が必要量を超えるとその場で進む(ゲームは止まらない)。ゲームの世界を止めるのはゲームオーバーのときだけ。強化画面と強化処理のコード、強化カードの画像、設計書A7_UpgradeSelectUI.mdは削除した。後半の手応えは、フェーズ表(敵の数と種類)と今後の敵の追加(C1)で作る。

- 2026-11-11: 氷霧の見た目・氷塊の見た目・破片の見た目を確定した(実装済み。[A3_Effects.md](A3_Effects.md))。氷塊の所持は、水平なリングから、頭の上の半径0.3の球の中を回る塊に変えた。破片は立方体8分割から球の殻の12分割に変え、重力・跳ね返り・摩擦を加えた。

- 2026-11-08: HPアイコンを、丸の画像(仮素材)から3Dの表示に置き換えた。被弾の表現は「一瞬大きく弾けてから暗くなる」から「核が砕け、欠片が枠の中に積もって暗くなる」に変えた。素材はPrimitive系統で統一し、UIは2D感を出す方針にした(人間の判断。[HUD_HpIcon3D.md](HUD_HpIcon3D.md)、[ArtDirection.md](ArtDirection.md))。
- 2026-11-08: HUD、被弾の表現、ゲームオーバー、連鎖数を確定した([C3_HUD.md](C3_HUD.md))。人間の判断で、Lvの文字と経験値バー、経験値玉の演出は廃止した。経験値は敵を撃破した瞬間に入る。

- 2026-11-08: 敵の「最大数」を、種類ごとからフェーズ全体の同時数に変えた(種類ごとの最大数は持たない)。フェーズごとのパラメーター調整はしない方針をやめ、フェーズ表で最大数、種類ごとの重み、1回に出す数、スポーンの間隔を持つ。強化は範囲、威力、移動速度の3つを毎回すべて並べる形に確定し、選択中はゲームを止める(詳細は[ProgressionDesign.md](ProgressionDesign.md))。
- 2026-11-06: 氷霧の「短い硬直」を、単押し・チャージ共通のクールタイム(既定0.1秒、移動は止めない)に置き換えた。オレンジの敵本体の破片は廃止した。自然解放は砕けではなく、殻が溶ける表現にした。
- 2026-11-05: 氷エリアの外では氷ゲージが、凍る速さと同程度に遅く減る。解放時は0に戻す。動いている敵どうしは押し合わない。後半の凍りにくさは閾値の高さで表し、自然に凍る上限は設けない。

- 2026-11-04: 「凍った敵は10秒ほどで自然に砕けて倒れる」と読める記述を、「10秒ほどで氷が砕けて解放される。倒れず氷塊も出ない」に確定。
