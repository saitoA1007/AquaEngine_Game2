# 見た目の方針(Art Direction)

確認日: 2026-11-08。[GameSpec.md](GameSpec.md)の「目指す体験」と「見た目」をもとにAIが下書きし、人間が確認した。仕様の正本はGameSpec.md。この文書は、素材を作るときの見た目の基準をまとめる。

- 「確定」は人間が採用した内容だけ。「検討中」と「未定」は、採用されるまで仕様として扱わない。

## 1. 確定

### 世界観

- 雪と氷の世界。溶けていく世界で、最後に残った「冷気の核」が主人公。敵を砕くほど、世界が再び凍っていく。
- 仮の参考は「凍土の番人」(世界観そのものは未確定。GameSpec.mdのとおり、モデルはこれをもとに作ってよい)。

### 色

- プレイヤーは氷属性で、水色系統。
- 敵は熱側で、オレンジ系統。
- 背景は白と青が混ざった少し暗い色。ライティングを映えさせる。

### 形と質感

- ボクセル調にはしない。
- 素材はPrimitive系統(単純な立体)で統一する。シンプルな見た目で完結し、プログラムでモーションを作りやすいため。
- ゲーム世界は、PBRとレイトレーシングを活かした、物理的な立体感のある見た目。

### UIとHUD

- UIとHUDは2D感を出す。3Dのモデルで作る場合も、影(面ごとの明暗)を付けず、平らな色で描く。
- 色はモデルや画像に焼き込まず、プログラムで掛ける(`DebugParameter`で調整できるようにする)。

### HPアイコン(3DのHUD)

- 六角形の枠の中に、正八面体の「冷気の核」をまっすぐ立たせて回す。
- 被弾すると、核が敵の氷と同じように砕ける。欠片は白く光らせず、残りの色から失った色へだんだん暗くなる。
- 欠片は枠の中だけで物理的に動き、底に積もって残る。これが失った状態の見た目になる。
- モデル: `Project/Resources/Models/HpHud/`の`hpFrame.gltf`(枠)、`hpCore.gltf`(核)、`hpCoreShard.gltf`(核を8個の欠片に分けたもの。ノード名は`HpCore_cell`)。表示の実装は別の設計で決める。

## 2. 検討中

- 自機の形を、HPアイコンの核と同じ正八面体などにする案。自機を作るときに考える(2026-11-08、人間の言葉は「自機作成の時に考えよう」)。

## 3. 未定

- 作品名。
- UIの文字の雰囲気と配色の細部。
- ボスの見た目。
- ストーリーの量と見せ方。

## 4. 素材の作り方

- 画像とモデルは人間が描かず、AIが作る。TD2_2の外部制作の仕組み(MCPでつないだBlenderとGIMP)を使う。採否は人間が決める。
- AquaEngineが読むモデルは`.obj`と`.gltf`だけ(`.glb`は読まない)。テクスチャは`Resources/Textures/`の下からだけ、名前で読む。
- 素材は名前で取得するので、フォルダが違っても同じファイル名は使えない。置く前に`Project/Resources`全体で名前を確かめる。
